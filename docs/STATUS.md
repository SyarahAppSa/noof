# حالة المشروع — ما اكتمل وما يحتاج ربطك أو اعتمادك

## ✅ مكتمل ومختبَر

- استقبال Webhook الرسمي من Meta مع التحقق من التوقيع ومنع التكرار، والإرسال عبر Cloud API (نص، أزرار، قوالب، تحميل وسائط).
- احترام نافذة 24 ساعة تلقائيًا: قوالب معتمدة خارجها، وتأجيل الرسائل وإرسالها عند رد الشخص.
- أوامر المالك والمدير بالعربية/اللهجة السعودية (محلل قواعد + Claude عند الغموض)، بما فيها الأوامر الصوتية بعد التحويل لنص.
- دورة حياة المهام: جديدة ← تم الاستلام ← تحت التنفيذ ← بانتظار مراجعة ← مكتملة / متأخرة / ملغاة، مع منع الانتقالات غير الصحيحة.
- تذكير كل 12 ساعة افتراضيًا، وأسرع للعاجل والمرتفع، وفترة مخصصة لكل مهمة، وتذكير قبل الموعد النهائي القصير، واحترام ساعات العمل.
- تنبيه التأخير الفوري للمالك والمدير المباشر (مرة واحدة)، وطلبات تمديد الموعد بموافقة.
- إثبات الإنجاز (ملف/صورة) والمراجعة والاعتماد، وسجل أحداث كامل لكل مهمة.
- العملاء: ملفات تلقائية، تصنيف الرسائل، فرص مبيعات، تنبيهات الشكاوى والعملاء المهمين، مسودات رد بانتظار الموافقة، ردود تلقائية من نصوص معتمدة فقط.
- المواعيد: إنشاء من واتساب، كشف التعارض، تأكيد بعد الموافقة، تذكير بملخص (الشخص، الشركة، آخر محادثة، المهام المفتوحة).
- التقارير: صباحي ومسائي مجدولان (بلا تكرار)، تقرير الموظفين، المتأخرات، «ما يحتاج قراري»، العملاء والفرص، وأهم 5 أمور.
- الصلاحيات (مالك/مدير/موظف/عميل) في واتساب والـAPI واللوحة، والموافقات الحصرية للمالك.
- التشفير، Audit Log غير قابل للتعديل، النسخ الاحتياطي، Docker + HTTPS.
- لوحة تحكم عربية RTL: الرئيسية، المهام، الموافقات (مع تعديل نص الرد)، العملاء والفرص، المواعيد، الرسائل، الفريق ومفاتيح API، سجل التدقيق، الإعدادات والردود المعتمدة وحالة الطابور.
- 64 اختبارًا آليًا ناجحًا على PostgreSQL حقيقية، وتشغيل فعلي للخادم والعامل في وضع التجربة.

## 🔌 جاهز في الكود ويحتاج مفاتيحك للتفعيل

| التكامل | المطلوب | الحالة |
|---|---|---|
| WhatsApp Cloud API | رقم نوف + توكن + App Secret + اعتماد 6 قوالب | الكود جاهز ومختبر بعميل وهمي؛ لم يُجرَّب على حساب Meta حقيقي بعد |
| Claude | `ANTHROPIC_API_KEY` | شكل الطلب مختبر عبر SDK؛ بدون مفتاح يعمل المحلل بالقواعد |
| تحويل الصوت | Azure Speech (ar-SA) أو OpenAI | جاهز؛ بدون مفتاح تُرفع الرسالة الصوتية لك كما هي |
| Google Calendar / Outlook | بيانات OAuth / تطبيق Azure AD | جاهز (إنشاء/تعديل/حذف حدث)؛ يحتاج تجربة على حسابك |
| CRM | رابط Webhook أو توكن HubSpot | جاهز بمحوّلات؛ لأي CRM آخر يُكتب محوّل صغير بنفس الواجهة |
| البريد | بيانات SMTP | إرسال التقارير بالبريد جاهز |

## ⏸️ ينتظر قرارك

1. **رقم نوف المستقل** (موصى به) — لم أسجل أي رقم.
2. **ربط رقمك الشخصي عبر Coexistence** — اختياري لاحقًا، لم يتم أي تغيير على رقمك.
3. **نصوص الردود التلقائية المعتمدة** (أوقات العمل، الموقع، الخدمات...) — أضفها من اللوحة.
4. **أوقات التقارير وساعات العمل** — الافتراضي 8:00 و18:00، الدوام 8–5، الأحد–الخميس.

## 🔜 مقترح للمرحلة التالية

- استقبال البريد الإلكتروني (IMAP/Graph) وربطه بالعميل والمهمة (طبقة البريد جاهزة للإرسال فقط حاليًا).
- محوّلات CRM إضافية حسب نظامك الحالي (Zoho، Salesforce، Odoo...).
- مزامنة عكسية من التقويم (المواعيد التي تُضاف يدويًا في Google/Outlook).
- مراقبة وتنبيهات تشغيلية (Sentry/Prometheus) عند النشر.
