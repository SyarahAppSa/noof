# نوف — مركز قيادة الشركة عبر واتساب

نوف مساعدة تنفيذية تدير المهام والموظفين والعملاء والمواعيد والمتابعات من خلال واتساب الرسمي (WhatsApp Cloud API)،
وترفع لك فقط ما يحتاج قرارك. توقيت النظام بالكامل بتوقيت **الرياض**.

## ماذا تفعل نوف

| المجال | ما يحدث |
|---|---|
| **المهام** | «أرسل لفهد تجهيز تقرير المبيعات اليوم قبل الساعة 2» ← مهمة رسمية برقم (T-12)، وأولوية، وموعد، وجهة مرتبطة، وإرسال للموظف مع أزرار «تم الاستلام / بدأت / تم الإنجاز» |
| **التذكير** | كل **12 ساعة** افتراضيًا حتى الإنجاز (عاجلة 3 س، مرتفعة 6 س، أو أي فترة: «تابع مع هيفاء كل 6 ساعات»)، داخل ساعات العمل ما عدا العاجل |
| **التأخير** | عند تجاوز الموعد: تنبيه فوري لك وللمدير المباشر، وتتحول الحالة إلى «متأخرة» |
| **الإنجاز** | لا تُغلق المهمة إلا بـ«تم» من الموظف، ومع ملف/صورة إن طُلب إثبات؛ ومراجعة واعتماد إن طُلبت |
| **السجل** | كل حدث محفوظ في سجل المهمة (لا يضيع في المحادثات) + Audit Log غير قابل للتعديل |
| **العملاء** | ملف تلقائي لكل رقم جديد، تصنيف الرسائل (عميل، مورد، عاجل، شكوى، موعد، فرصة، متابعة، شخصية)، فرص مبيعات، تذكير بمن لم نتابعه |
| **الردود** | رد استلام مهذب + ردود تلقائية **من نصوص معتمدة منك فقط**. الشكاوى والأسعار والالتزامات ← مسودة رد لك للموافقة |
| **المواعيد** | «أضف موعدًا مع العميل خالد يوم الثلاثاء الساعة 11» ← موعد + مزامنة Google/Outlook + تأكيد للطرف الآخر بعد موافقتك + تذكير قبل الموعد بملخص |
| **التقارير** | 8:00 ص و6:00 م (قابلة للتعديل) + «ماذا يحتاج قراري الآن؟» في أي وقت |
| **الصوت والصور** | الرسائل الصوتية ← نص (حتى أوامرك الصوتية تُنفذ). الصور والمستندات ← استخراج المبالغ والتواريخ والأطراف وربطها بالعميل/المهمة |

## البنية التقنية

- **Backend**: Python 3.13 + FastAPI، API منظم `/api/v1` (توثيق تفاعلي على `/docs` خارج الإنتاج).
- **قاعدة البيانات**: PostgreSQL 16 + Alembic migrations.
- **الطابور والجدولة**: طابور داخل PostgreSQL (`FOR UPDATE SKIP LOCKED`) — كل رسالة/تذكير يُكتب في نفس معاملة قاعدة البيانات فلا يضيع عند الانقطاع، مع إعادة محاولة بتأخير أسي، ومنع التكرار، وقفل للمجدول يسمح بتشغيل أكثر من عامل.
- **الذكاء الاصطناعي**: Claude (Anthropic) بمخرجات JSON مقيدة بمخطط لفهم الأوامر والتصنيف والصور والمستندات. عند تعطله يعمل النظام بمحلل عربي بالقواعد.
- **التكاملات**: WhatsApp Cloud API، Google Calendar / Outlook (Graph)، طبقة CRM بمحوّلات (داخلي، Webhook موقّع، HubSpot)، SMTP، تحويل الصوت (Azure Speech ar-SA أو Whisper).
- **لوحة تحكم** عربية RTL بسيطة (عند الحاجة فقط).

```
app/
  main.py            تطبيق FastAPI
  worker.py          العامل الخلفي + المجدول
  models.py          نموذج البيانات
  whatsapp/          عميل Cloud API، تحليل Webhook، صندوق الصادر ونافذة 24 ساعة
  services/          المهام، الموافقات، العملاء، المواعيد، التقارير، معالجة الوارد، تنفيذ الأوامر
  nlp/               توحيد العربية، تحليل التواريخ، محلل الأوامر
  ai/                Claude + تحويل الصوت
  integrations/      التقويم، CRM، البريد
  api/               Webhook، REST، لوحة التحكم
migrations/          Alembic
scripts/             إنشاء المالك، بيانات تجريبية، نسخ احتياطي، توليد مفاتيح
tests/               64 اختبارًا (مهام، تذكيرات، صلاحيات، أمان، عملاء، تقارير...)
```

## التشغيل السريع (خادم إنتاج)

```bash
cp .env.example .env
python3 -m scripts.genkey        # انسخ المخرجات إلى .env
# عبّئ بقية القيم في .env (واتساب، Claude، النطاق...)
docker compose up -d --build
docker compose exec web python -m scripts.create_owner --name "اسمك" --phone 05XXXXXXXX --company "اسم الشركة"
```

ثم اربط واتساب حسب [docs/WHATSAPP_SETUP.md](docs/WHATSAPP_SETUP.md)، وادخل اللوحة: `https://نطاقك/dashboard`،
وأضف فريقك من «الفريق» (الاسم، الجوال، الدور، المدير المباشر، أسماء مختصرة مثل «فهد»).

الخدمات: `web` (API + لوحة)، `worker` (الطابور والتذكيرات والتقارير)، `db`، `backup` (نسخة يومية مضغوطة في `./backups`)، `caddy` (HTTPS تلقائي).

## التشغيل المحلي للتطوير

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements-dev.txt
cp .env.example .env    # APP_ENV=development و WA_DRY_RUN=true
alembic upgrade head
python -m scripts.seed_demo            # بيانات تجريبية موسومة [تجريبي]
uvicorn app.main:app --reload          # نافذة 1
python -m app.worker                   # نافذة 2
```

في وضع `WA_DRY_RUN=true` لا يُرسل شيء لواتساب؛ الرسائل تظهر في سجل العامل.
حذف البيانات التجريبية: `python -m scripts.seed_demo --purge`.

## أوامر واتساب (أمثلة)

| تكتب لنوف | النتيجة |
|---|---|
| أرسل لفهد تجهيز تقرير المبيعات اليوم قبل الساعة 2 | مهمة + إرسال لفهد + تذكير كل 12 ساعة |
| كلف سارة بمراجعة العقد بكرة الساعة 11 عاجل مع إثبات | مهمة عاجلة (تذكير كل 3 ساعات) تتطلب ملفًا عند الإنجاز |
| تابع مع هيفاء كل 12 ساعة حتى تنهي الموضوع | ضبط متابعة مهمتها المفتوحة (أو إنشاء مهمة متابعة) |
| تابع مع شركة الأفق بخصوص عرض السعر | مهمة للموظف المسؤول + مسودة رسالة للعميل بانتظار موافقتك |
| أضف موعدًا مع العميل خالد يوم الثلاثاء الساعة 11 | موعد + تقويم + طلب موافقة لإرسال التأكيد |
| من لديه مهام متأخرة؟ | قائمة المتأخرين حسب الموظف |
| ماذا يحتاج قراري اليوم؟ | موافقات معلقة، تأخيرات حرجة، رسائل عملاء، طلبات موظفين |
| أرسل تقرير الموظفين اليومي / التقرير الصباحي / المسائي | التقرير فورًا |
| ما هي أهم العملاء والفرص التي لم نتابعها؟ | عملاء بلا متابعة + فرص مفتوحة |
| موافق A-5 / ارفض A-5 / رد A-5: نص ردك | قرار على طلب موافقة (أو إرسال ردك بدل المقترح) |
| حالة المهمة T-12 / الغاء المهمة T-12 | حالة وسجل المهمة / إلغاؤها |

**الموظف**: «تم» (مع ملف إن لزم)، «استلمت»، «جاري»، «مهامي»، «أحتاج وقت أقدر أسلمها بكرة الساعة 12» (طلب تمديد يحتاج موافقة).
عند وجود أكثر من مهمة تسأله نوف أيها يقصد، أو يرد على رسالة المهمة مباشرة.

## الصلاحيات

| الدور | الصلاحيات |
|---|---|
| المالك | كل شيء + كل الموافقات |
| المدير | تكليف ومتابعة فريقه فقط، تقارير فريقه، اعتماد إنجاز مهام فريقه |
| الموظف | مهامه وطلباته فقط |
| العميل/الطرف الخارجي | لا يرى أي بيانات داخلية إطلاقًا |

**إجراءات لا تتم إلا بموافقتك الصريحة**: أي رد جديد لطرف خارجي غير معتمد مسبقًا، الأسعار النهائية، العقود، الإجراءات المالية،
الالتزامات الرسمية، حذف البيانات، الرسائل الجماعية، وتأكيد المواعيد للطرف الآخر.

## الأمان

- الأسرار في متغيرات البيئة فقط. النظام يرفض الإقلاع في الإنتاج دون `SECRET_KEY` و`ENCRYPTION_KEY` و`WA_APP_SECRET`.
- تشفير محتوى الرسائل والملاحظات والتقارير في قاعدة البيانات (Fernet / AES).
- سجل تدقيق غير قابل للتعديل أو الحذف (Trigger في PostgreSQL).
- لوحة التحكم: bcrypt، جلسات موقعة، حماية CSRF، تحديد محاولات الدخول، ترويسات أمان، HTTPS.
- API: مفاتيح لكل مستخدم مخزنة كـ hash، وصلاحيات حسب الدور.
- النسخ الاحتياطي يومي مع احتفاظ 14 يومًا. **احفظ `ENCRYPTION_KEY` منفصلًا عن النسخ الاحتياطية.**
  الاستعادة: `gunzip -c backups/noof_XXXX.sql.gz | docker compose exec -T db psql -U noof noof`

## الإعدادات القابلة للتعديل (من اللوحة ← الإعدادات أو `PATCH /api/v1/settings`)

أوقات التقارير، ساعات وأيام العمل، فترات التذكير (افتراضي/مرتفع/عاجل)، تذكير المواعيد، مدة اعتبار العميل بلا متابعة،
أسلوب الرد، الردود التلقائية المعتمدة، رد الاستلام، الإثبات الافتراضي.
